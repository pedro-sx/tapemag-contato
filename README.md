Central de atendimento digital desenvolvida para a **TAPEMAG**, permitindo que clientes encontrem rapidamente o vendedor desejado e iniciem uma conversa diretamente pelo WhatsApp.

## Sobre o projeto

O **TAPEMAG Contato** é uma landing page responsiva criada para simplificar o atendimento comercial da empresa. A aplicação reúne todos os vendedores em uma única interface, oferecendo pesquisa em tempo real, acesso rápido aos contatos e uma experiência moderna tanto no desktop quanto no mobile.

## Preview

> Interface limpa, pesquisa instantânea e acesso direto ao WhatsApp dos vendedores.

## Funcionalidades

* Pesquisa de vendedores em tempo real
* Redirecionamento direto para WhatsApp
* Tema claro/escuro
* Links para Instagram, Facebook e LinkedIn
* Interface responsiva para dispositivos móveis
* Animações e efeitos visuais leves para melhor experiência

## Tecnologias utilizadas

## Como executar

1. Clone o repositório

```bash
git clone https://github.com/pedro-sx/tapemag-contato.git
```

2. Entre na pasta

```bash
cd tapemag-contato
```

3. Abra o arquivo `index.html`

Ou utilize uma extensão como **Live Server** no VS Code.

## Objetivo

O projeto foi desenvolvido para reduzir o tempo entre o cliente encontrar um vendedor e iniciar o atendimento, substituindo listas de contatos por uma experiência muito mais intuitiva.
